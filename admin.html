    How sounds are matched

    A player's sound plays instead of the standard buzz. Load them before players arrive: name each WAV or MP3 after the player, e.g. Alice.mp3 or Mary Jo.wav. Anyone who joins with that name gets it automatically; capitals, spaces and punctuation are ignored. If a name doesn't match, use Assign to. Add sound in the player list uploads one for that player directly. Sounds are stored on the message server under this room code and are deleted automatically after 14 days.
